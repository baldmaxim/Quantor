# T02. Веб: страница «Расчёты», база объекта, токены

После T01 и генерации клиента. Флаг `tender.exchange` (из `/meta`) закрывает всё ниже; нет флага — пунктов меню
и маршрута нет (маршрут отвечает «возможность выключена», как у других пилотов). Права — из сеанса.

## Маршрут `apps/web/src/app/(portal)/projects/[projectId]/calcs/page.tsx`

Пункт «Расчёты» в навигации проекта рядом с «3D»/«Вопросы к документации». Три раздела (вкладки):

1. **Расчёты** — карточки репозиториев, группировка по разделу (Механика / ЭОМ / СС), подписи систем по-русски
   (словарь кодов из формата: heating → «Отопление», fire_sprinkler → «АУП», power → «Силовое электрооборудование»…).
   В карточке: название, последняя версия (`№N · label`), автор, дата, выпуск базы `#n`, значок «база устарела»,
   число предупреждений. Клик → история версий (таблица как список коммитов: №, подпись, сообщение, автор, дата,
   sha256 первые 8, статус; отозванная — зачёркнута) → карточка версии:
   - объёмы: таблица по `group`, колонки «Код, Наименование, Ед., Кол-во, Было, Δ» (`diff` из API), строки
     added/removed/changed подсвечены токенами темы; фильтр «только изменения»; на телефоне — карточки строк;
   - по этажам: раскрытие строки → `per_floor`;
   - вопросы; предупреждения; привязка (`fit`: оси, rms, max);
   - виды: список «документ, лист, этажи» со ссылками «Открыть на листе» (рабочая область CAD этого вида со
     включённым слоем этой версии — параметры маршрута как у существующих ссылок на вид) и «3D этажа»;
   - «Скачать пакет», «Отозвать версию» (право `tender.calc.withdraw`, подтверждение).
2. **База объекта** — выпуски (номер, дата, кто, видов, с DXF, размер, комментарий, «Скачать», «Отозвать» для
   координатора). Кнопка «Выпустить базу» (право `tender.base.release`) → окно: кандидаты `base/candidates`
   деревом корпус → секция → этажи с флажками (по умолчанию все совмещённые; несовмещённые и без кадра —
   с пометкой), «С DXF планов», комментарий → POST → строка нового выпуска со «Скачать». Подсказка: «Скачанный ZIP
   положите в TENDER/Работа/Quantor/Базы/<объект>/».
3. **Доступ для TENDER** — личные токены: создать (название, срок) → окно с токеном один раз, кнопка «Копировать»,
   предупреждение «больше не покажем»; список (название, префикс, создан, последний вход, срок, «Отозвать»).
   Подсказка команды: `python3 calc_push.py --portal https://quantor.meridianai.ru --token-file …`.

## Код

- Запросы — `apps/web/src/lib/tender/queries.ts` (TanStack Query, генерируемый клиент), словари систем —
  `lib/tender/systems.ts` (общие с T03 — создать здесь), компоненты — `components/tender/*` (≤ 500 строк на файл).
- Правила `Odintsov/CLAUDE.md`: mobile-first 360 px, цвета только токенами темы, поля с крестиком через общий
  компонент поля, тап-цели ≥ 44 px, без inline-стилей.
- Проверка: `pnpm --filter web lint typecheck test`, сборка web; скриншоты 390 px и 1280 px обеих тем.
