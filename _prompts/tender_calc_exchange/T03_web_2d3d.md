# T03. Веб: слой «Расчёты» в 2D и 3D, скрытие ВИС движка

После T01. Параллельно T02: общий только `lib/tender/systems.ts` (создаёт T02; если его ещё нет — создай с тем
же экспортом `SYSTEM_LABELS`, `systemColorToken(system)`). Флаг `tender.exchange` закрывает слой.

## Данные

`lib/tender/layers.ts`: `useTenderViewLayers(projectId, revisionId, pageIndex, view)` → `GET …/tender/view-layers`;
`useTenderViewGeometry(versionId, revisionId, pageIndex, view)` → геометрия вида; `useTenderBuildingLayers`.
Видимость слоёв — в существующем хранилище видимости слоёв CAD (единые 2D↔3D, как «Слои»), ключ
`tender:<calc_id>`; по умолчанию включены.

## 2D (наложение на лист, Canvas2D)

- В `CadLayersPanel` — группа «Расчёты»: строка на версию («Отопление · №3 v3»), флажок, значок «база устарела».
- Рисование — через кадр вида (`lib/cad/frame.ts`, тот же путь, что трассы движка): полилинии (x, y) линией,
  толщина по `kind` (tray/duct толще), цвет — по системе; `riser` — кружок; элементы — значок: `terminal`/
  `equipment` — квадрат, `valve`/`fitting` — ромб, `sleeve` — короткий штрих. Подпись `mark` — при крупном зуме.
- Клик по объекту — плашка: расчёт, версия, система, `id`, Ø/сечение, марка, квартира, примечание.

## 3D этажа (`components/workspace/cad/floor3d/CadFloor3dView.tsx`)

- Геометрию расчёта перевести в вход существующих построителей (`lib/cad/floor3d-routes.ts`,
  `floor3d-mep-elements.ts`): `kind` cable/tray/duct → прямоугольное сечение или линия, `equipment` → коробка.
  Типы входа расширить аддитивно, поведение трасс движка не менять. Выбор кликом — та же плашка, что в 2D
  (`floor3d-mep-pick.ts` — источник «расчёт»).

## 3D здания

- Просмотрщик объекта (`components/projects/building3d/BuildingViewerCanvas.tsx`) и вид «Здание» CAD: для этажа,
  ключ вида которого есть у активной версии, геометрия ставится как этаж: `+offset_mm`, `z + base_z_mm`.
  Логика — в новом `lib/tender/building-calc-layer.ts`; в файлы просмотрщика — только вызов (их параллельно
  правит другая сессия: минимальная вставка, без перестройки).
- Переключатель расчётов в панели просмотрщика; ленивая загрузка видов, предел одновременных запросов 6.

## ВИС движка за флагом `cad.mep_engine`

Флаг выключен → скрыть: кнопки построения/перестроения трасс и панели трасс (`components/cad/mep/*`), слои
трасс движка в 2D (`mep-layers.ts`), трассы и элементы движка в 3D этажа и здания. Одобрение вида, зоны,
конструкции, реестр стояков — без изменений.

Проверка: lint, typecheck, vitest (`lib/tender/*`: перевод в кадр, сдвиг этажа, видимость), сборка;
скриншоты 2D, 3D этажа, 3D здания на синтетике (390 и 1280 px).
