# Fixtures policy Stage 2B

В git можно хранить только синтетические данные:

- маленький synthetic PlanSwift-like XML, созданный специально для теста;
- маленькие PNG/TIFF с искусственными прямоугольниками/линиями/holes;
- expected JSON manifests/masks/vectors.

Нельзя помещать сюда фрагменты реальных проектов Stories/Мосфильмовская, даже «один лист для
удобства», без отдельного разрешения владельца на републикацию внутри repo.
