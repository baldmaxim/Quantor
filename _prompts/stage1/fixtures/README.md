# Fixtures

Каталог для тестовых пакетов распознавалки. Содержимое **не коммитится** (см. корневой `.gitignore`) — архивы весят десятки мегабайт.

## legacy/

Пакеты текущего формата `recognized-package/legacy-v1`: исходный PDF + `*_blocks.json` + `*_results.md` + опциональный `*_results.html`.

Эталонный пример: `01-03-00-01-12_ПД-00260560-АР.zip` (~47 МБ).

Ожидаемые значения для acceptance-теста импорта (промт 06):

| Метрика | Значение |
|---|---|
| `schema_version` | 1 |
| `coordinate_space` | `normalized_page_top_left` |
| Страниц PDF | 77 |
| Регионов всего | 383 |
| `text` | 230 |
| `image` | 90 |
| `stamp` | 63 |
| Прямоугольников / полигонов | 380 / 3 |
| Блоков с `crop_url` | 320 |
| Секций в `results.md` | 320 (text + image; stamp-блоки секций не имеют) |

Эти числа — утверждения теста на фикстуре, а не константы продукта. В коде портала их быть не должно.

## Как получить архив на другой машине

Архив не входит в репозиторий. Скопируйте его вручную в `_prompts/stage1/fixtures/legacy/`, после чего интеграционный тест импорта подхватит его автоматически; без архива тест пропускается (`skip`), а вместо него работает синтетическая мини-фикстура.
