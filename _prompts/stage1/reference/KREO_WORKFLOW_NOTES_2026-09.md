# Kreo workflow notes used as UX inspiration (not implementation copying)

Checked against Kreo public material in late Aug / early Sep 2026.

Useful workflow principles:
- Project is the main working unit and may contain multiple files/pages.
- File Manager + quick access to open pages.
- Measurements stored/grouped in a nested manager.
- Geometry and quantities are structured project data, not just painted pixels.
- AI searches run asynchronously and return job/status/results.
- PDF/CAD/images are accepted input types.
- Reports remain linked to measurements.
- Drawing comparison/revisions are first-class later capability.
- AI and manual measurements coexist; AI output is expected to be reviewed.
