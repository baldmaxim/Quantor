# План: согласованность комплекта и связь АР ↔ ИОС

Основание — [ADR-0043](../adr/0043-soglasovannost-komplekta-i-svyaz-ar-ios.md). По одному этапу, STOP после
каждого; следующий — по команде владельца. Флаг `project.consistency`.

Объекты приёмки (вне git): **328 «Остров 14»** и **314 «События 6.1»**; 342 — регрессия пилота.

## Каталог проверок v1 (по мере появления данных)

- Комплектность: ведомость листов ↔ листы; план АР на каждый уровень; схема на каждую систему ИОС.
- ПЗ ↔ каркас: этажность, высоты этажей, отметки.
- Экспликация ↔ зоны CAD: состав помещений, площади в допуске.
- Квартиры: экспликация квартир АР ↔ квартиры по зонам (квартирографии в 328/314 нет).
- Шахты АР ↔ стояки ИОС: количество, принадлежность шахте, непрерывность по уровням.
- План ИОС ↔ план АР (после С3): стояк в шахте, прибор в своём помещении.
- ВОР ↔ CAD: группы — есть; количества — сверка, не вход расчёта (у 328 и 314 ВОР только PDF — не проверяется).
- ТЗ ↔ решения: ручной список требований.

## Предусловия на данных

- ZIP-пакета распознавалки у 328 и 314 нет: факты ПЗ и таблиц в calc без него не извлекаются. Решить: прогон
  распознавалки или кандидаты паспорта только по текстовому слою PDF (С1 работает и без ZIP).
- Загрузка в портал — какой стенд (локальный или бой) решает владелец.
- Объём: 328 — 128 PDF, ~7,3 тыс. стр., ~2,5 ГБ; 314 — 114 PDF, ~9,2 тыс. стр., ~2,1 ГБ. Паспорт листа (С1) — на весь
  комплект (только текстовый слой); CAD-обработка (С3–С5) — на выборке: один корпус и секция, план АР типового
  этажа + схемы ИОС2/ИОС3/ИОС4 + ПЗ + состав проекта (СП).
- Найдено описью и само по себе проверка С1/С2: у 314 шифры РД не совпадают с шифром П; у 328 корпус виден в имени
  только у 18 из 128 файлов, ТЗ в двух вариантах (корп. 1 и корп. 2–6); у обоих есть состав проекта П, нет состава РД.
