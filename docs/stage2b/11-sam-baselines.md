## 1. Что сравнивается

| Политика | Подсказка SAM                                                                     | Откуда подсказка                                              |
| -------- | --------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| `auto`   | сетка 16 × 16 точек по тайлу; из каждой — лучшая из трёх масок SAM                | только изображение тайла                                      |
| `coarse` | связные области маски малого U-Net → рамка + самая уверенная точка каждой области | прогноз `slab-tinyunet-b16-v1` с его замороженным порогом 0,5 |

Для сравнения рядом — сам малый U-Net (промт 10): test IoU 0,135, ошибка площади листа 85 %.

**`auto` — честный SAM-only baseline.** Семантики «плита» у SAM нет: сетка точек даёт маски помещений,
рамок, подписей. Остаются маски с оценкой SAM ≥ 0,85, площадью 2–90 % тайла и светлой
внутренностью (≥ 90 % светлых клеток). Ожидаемо собирает лишнее — это и измеряется.

**`coarse` — уточнитель.** SAM по рамке с точкой оставляет отверстия сам и подтягивает маску к линиям
чертежа — ровно то, чего не хватило U-Net (Boundary F1 0,021 на val). Области меньше 4 096 px² и сверх
8 крупнейших на тайл отбрасываются; маски SAM с оценкой < 0,5 не входят.

Объединение масок — максимум логитов на сетке SAM (256 × 256), затем одно увеличение до 1 024 px.

## 2. Модель и зависимости

- **SAM 2.1 через `transformers` 5.5.0** (`Sam2Model`, `Sam2Processor`), официальные веса Meta в
  формате `transformers`, по закреплённым ревизиям; SHA-256 `model.safetensors` пишется в запись прогона.

| Размер      | Репозиторий                       | Ревизия                                    |
| ----------- | --------------------------------- | ------------------------------------------ |
| `tiny`      | `facebook/sam2.1-hiera-tiny`      | `de431c4043854a71d8101e17995dfe596bf101a5` |
| `small`     | `facebook/sam2.1-hiera-small`     | `ee5bba1d82bb8749febdf90f45e84b687142ba03` |
| `base-plus` | `facebook/sam2.1-hiera-base-plus` | `b7320756a13354e7530a63935656d35b2f91a290` |

- **Пакет `sam2` с PyPI не используется и заблокирован:** под этим именем опубликован сторонний форк
  (`JinsuaFeito-dev/segment-anything-2`), а не код Meta — риск подмены пакета. В матрице он до этого
  промта стоял `allow` по лицензии репозитория Meta; исправлено.
- **MobileSAM не выполнен.** На PyPI его нет; код ставится только из git и тянет `timm` без решения в
  матрице, веса лежат в репозитории, а не в формате `transformers`. Промт допускает его «если
  зависимость/runtime стабильны» — здесь это не так. Включить можно отдельным решением владельца:
  закреплённый коммит, аудит `timm`.
- `transformers` 5.5.0 выбран под ограничение Unsloth (`≤ 5.5.0`), чтобы окружения не расходились.

## 3. Защита от утечки и от подбора по test

- **Подсказки без разметки — по построению.** Функции подсказок принимают только изображение или
  вероятность другой модели; параметра для разметки у них нет. Тест: те же изображения с другими
  масками истины дают побайтно те же прогнозы.
- **`coarse` использует модель, обученную только на train;** её веса сверяются по SHA-256 из её
  `run.json`, разбиение — по `split_sha256`.
- **Настройки фиксируются на val.** Первый прогон пишет `sam-run.json` с настройками и их SHA-256;
  другие настройки под тем же `--run-id` — отказ.
- **Test — один раз на политику.** Прогон на test берёт настройки только из своего `sam-run.json`,
  требует готовый val того же прогона и отказывает, если политика уже была на test. Второй test той
  же политики — только с `--new-experiment "причина"`, причина пишется в `sam-test-registry.json`.
- **Дымовой прогон (`--limit-tiles`) на test не допускается.**

## 4. Метрики и стоимость

Метрики — общий модуль с промтом 10 (`slab/evaluation.py`): IoU, Dice, Boundary F1 (2 px), ошибка
площади по тайлу, **ошибка нетто-площади по листу со сшивкой**, задержка на тайл (эмбеддинг + все
подсказки + объединение), пик видеопамяти, маски прогнозов с SHA-256. Порог по маске — 0,5.

Победителя по IoU здесь не объявляем: выбор по метрикам QTO — промт 18.

## 6. Запуск на RTX 5050

Один раз добавить `transformers` в окружение обучения (веса SAM скачаются с Hugging Face при первом
запуске — это публичные веса Meta, клиентские данные никуда не уходят):

```powershell
cd vision
.\.venv-train\Scripts\python -m pip install transformers==5.5.0
$B = "$env:QUANTOR_DATASET_ROOT\planswift\build\planswift-build-v1"
$U = "$env:QUANTOR_DATASET_ROOT\runs\slab-tinyunet-b16-v1"
```

**Шаг 1 — дымовой прогон на GPU:**

```powershell
.\.venv-train\Scripts\python -m quantor_vision sam run --build $B --run-id sam-smoke-gpu --policy coarse --coarse-run $U --limit-tiles 4
```

**Шаг 2 — val, обе политики, SAM small:**

```powershell
.\.venv-train\Scripts\python -m quantor_vision sam run --build $B --run-id sam-coarse-small-v1 --policy coarse --coarse-run $U
.\.venv-train\Scripts\python -m quantor_vision sam run --build $B --run-id sam-auto-small-v1 --policy auto
```

Прислать оба `val-metrics.json`. По желанию для стоимости — `coarse` с `--model tiny` и `--model base-plus`
под своими `--run-id`.

**Шаг 3 — test, один раз на политику** — после обсуждения val; настройки не меняются:

```powershell
.\.venv-train\Scripts\python -m quantor_vision sam run --build $B --run-id sam-coarse-small-v1 --split test
.\.venv-train\Scripts\python -m quantor_vision sam run --build $B --run-id sam-auto-small-v1 --split test
```

## 7. Ограничения

- `auto` не различает плиту и прочие замкнутые области — без классификатора его точность по
  определению низкая; он фиксирует, сколько даёт SAM сам по себе.
- `coarse` не находит плиту там, где её пропустил U-Net: SAM уточняет, но не ищет. Полнота
  ограничена полнотой U-Net.
- Термовкладыши ≈ 9 × 7 px рабочего растра ≈ 2 × 2 клетки сетки масок SAM — отверстия такого размера
  SAM, скорее всего, тоже не удержит.
- Дообучение SAM не начато: промт разрешает его только после отчёта о конкретной ошибке и решения
  владельца.
