## 1. Что оказалось в формате

Проект PlanSwift — дерево каталогов, в каждом `Data.xml` с одним `Item`:

| Где                               | `Class`                                           | Что нужно импорту                                          |
| --------------------------------- | ------------------------------------------------- | ---------------------------------------------------------- |
| корень                            | `Item` (Type `Job`)                               | имя проекта                                                |
| `Pages/<лист>/`                   | `Page`                                            | GUID листа, `Image GUID` → `{GUID}.tiff` рядом, `ScaleX/Y` |
| `Takeoff/…/<позиция>/`            | `Area`, `Linear`, `Count`, `Folder`, `Item`       | семантическое имя позиции                                  |
| `…/<позиция>/<секция>/`           | `Area Section`, `Linear Section`, `Count Section` | `PageGUID`, `DigitizerData`                                |
| `…/<секция площади>/<вычитание>/` | `Area Subtract Section`                           | **нет** `PageGUID` — лист родителя                         |

- `DigitizerData` — вложенный XML `<Points><Point X Y PointType/>`. Координаты — **пиксели растра
  листа**: ни одна из 18 967 принятых точек двух проектов не вышла за размер TIFF, максимум — 0,95 стороны.
- Дуги уже развёрнуты: `Normal … ArcChild* Arc ArcChild* … Normal`; `Arc` лежит на кривой вместе с
  соседями. Все точки сохраняются в исходном порядке, тип точки — рядом (`point_types`).
- Кодировка: 6 273 файла из 6 279 объявляют UTF-8 и записаны в cp1251; 6 — настоящий UTF-8.
- В `ScaleX`/`ScaleY` десятичная запятая; значения хранятся строкой как свидетельство.
- Имена каталогов усечены; имя позиции и листа берётся из свойства `Name` в XML.

## 2. Правила импорта

| Правило                            | Реализация                                                                                          |
| ---------------------------------- | --------------------------------------------------------------------------------------------------- |
| кодировка                          | BOM → объявленная не-UTF-8 → строгий UTF-8 → cp1251; откат считается (`xml_cp1251_fallback`)        |
| недоверенный XML                   | DOCTYPE/ENTITY отвергаются до разбора, предел 32 МиБ на файл; ссылки наружу из дерева не читаются   |
| недоверенный `.7z`                 | системный `7z`: оглавление без абсолютных путей и `..`, суммарно ≤ 4 ГиБ, распаковка вне git        |
| лист                               | `PageGUID`; растр по `Image GUID`, SHA-256, размер из IFD TIFF                                      |
| вычитание                          | наследует лист родительской `Area Section`, `page_guid_inherited: true`; родитель отвергнут → отказ |
| счёт                               | секция с N точками — `object_count = N`                                                             |
| заглушки `(-1, -1)`                | все точки — `placeholder_coordinates`, часть — `partial_placeholder_coordinates`                    |
| за краем растра, мало точек, пусто | `outside_image`, `too_few_points` (линия < 2, контур и отверстие < 3), `no_points`                  |
| масштаб                            | `ScaleX/ScaleY/Scale Units` строкой в `scale_evidence`; в калибровку Quantor не превращается        |
| ремонт геометрии                   | нет: повторы вершин и самопересечения остаются как нарисованы — их оценивает промт 07               |
| ожидаемые числа                    | в разборе нет; `stats --expect` сверяет с `tools/planswift_gt/expectations/reference-r2.json`       |

## 3. Формат `planswift-gt-v1`

Каталог из открытых текстовых файлов, без базы и без меток времени:

```text
manifest.json       формат, версия инструмента, dataset_id, project_key, сводка, SHA-256 файлов ниже
pages.jsonl         page_guid, name, image{path, sha256, width_px, height_px}, scale_evidence, source_xml_sha256
annotations.jsonl   строка контракта GroundTruth v1 на секцию
rejections.jsonl    source_path, source_xml_sha256, section_class, guid, reason, detail
```

Строка аннотации — контракт плюс свидетельства воспроизводимости:

```json
{
  "dataset_id": "planswift-gt-v1:mosfilm31a",
  "source": "planswift",
  "project_key": "mosfilm31a",
  "page": { "page_guid": "{…}", "image_sha256": "…", "width_px": 8608, "height_px": 6081 },
  "annotation": {
    "id": "{GUID секции}",
    "kind": "polyline | polygon | polygon_hole | count",
    "section_class": "Area Subtract Section",
    "label_raw": "имя позиции из XML",
    "label_path": ["папка", "позиция"],
    "points_normalized": [[0.0, 0.0]],
    "points_source_px": [[0.0, 0.0]],
    "point_types": ["Normal"],
    "object_count": 1,
    "parent_annotation_id": "{GUID контура} | null",
    "page_guid_inherited": true,
    "source_path": "Takeoff/…/Data.xml",
    "source_xml_sha256": "…"
  }
}
```

Нормализация — `x / width_px`, `y / height_px` исходного растра, без округления; исходные пиксели
лежат рядом. Растры не копируются: на них ссылаются путь от корня проекта и хеш. JSONL выбран вместо
Parquet: читается `diff`, `jq` и стандартной библиотекой, без зависимостей на машине с данными.

## 5. Команды

```bash
pnpm planswift inspect  <распакованный проект | архив.7z --work-dir DIR>
pnpm planswift convert  <проект> --project-key mosfilm31a --out DIR   # или QUANTOR_DATASET_ROOT
pnpm planswift validate DIR --source <корень проекта>
pnpm planswift stats    DIR --expect expectations/reference-r2.json
pnpm test:planswift     # ruff, mypy strict, pytest на синтетике
```

`pnpm planswift` запускает инструмент интерпретатором venv бэкенда с рабочим каталогом
`tools/planswift_gt` — относительные пути считаются от него.

## 7. Ограничения и открытое

- **Геометрия не проверена на валидность** — повторы соседних вершин (4 принятые секции Мосфильмовской) и возможные
  самопересечения остаются как в PlanSwift. Это задача промта 07 вместе с визуальной сверкой.
- **Вычитание, чей родитель — не `Area Section`,** отвергается (`hole_parent_missing`); на двух
  архивах таких нет.
- **Метки времени и автор** из XML не переносятся: для ground truth не нужны, а автор — персональные
  данные.
- **Растр читается только классический TIFF.** Другие форматы листа дадут `page_image_unavailable`
  с причиной — на двух архивах все 48 листов TIFF.
- Путь к данным на этой машине — `C:\Users\Usrr\QuantorData\planswift\{raw,gt,work}`; на выделенном
  dataset host — `QUANTOR_DATASET_ROOT`.
