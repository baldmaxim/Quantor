Дата: 2026-09-11. Baseline снят на коммите `dfcb038` до любых правок этапа.

- **Baseline Stage 2A на стенде зелёный:** 684 теста API прошли, пропусков ноль — тесты на базе
  выполнены по-настоящему.

### Флаг закрывает возможность

Аудит 00 нашёл, что выключенный `takeoff.manual` ничего не прятал: вкладка «Обмеры» была
включена жёстко, API обмера флаг не проверял. Для гейта `MANUAL_FLAG_PILOT_SAFE` этого было
недостаточно, поэтому:

- **Сервер.** Маршрутизаторы обмера и калибровки зависят от `require_feature("takeoff.manual")`
  (`apps/api/app/api/v1/deps.py`). Выключен — `403 FEATURE_DISABLED`, без сеанса по-прежнему 401. Флаг вычисляется тем же провайдером, что и `/api/v1/meta`.
- **Портал.** Вкладка «Обмеры», инструменты счёта, линии, ломаной, площади и масштаба выключены и
  подписаны «Этап 2A · пилот — включается администратором для пространства»; запросы обмера не
  отправляются (`apps/web/src/components/workspace/takeoff-access.ts`).
- **Админка.** У пилотной возможности есть «Включить в пространстве» и «Сбросить для
  пространства» — для текущего пространства администратора. Включить пилот владельцу:
  админка → Флаги возможностей → «Ручные измерения» → «Включить в пространстве».

### Найдено по дороге: флаг терялся при гидратации

Первая версия сценария «вкладка обмеров открывается при включённом пилоте» падала через раз — 8
падений из 10 повторов. Это была не хрупкость теста, а дефект портала.

Сервер рендерит рабочую область без `meta`, то есть с выключенной вкладкой. Боковая рейка
гидрируется раньше страницы и успевает получить `meta`. Страница затем гидрируется уже с
включённым флагом, но **React 19 не исправляет расхождение атрибутов при гидратации**: `disabled`
из серверной разметки оставался навсегда, хотя состояние компонента было «включено» и запрос строк
обмера уже уходил. Проверено отладочной сборкой: рендер видел `enabled=true`, DOM — `disabled`.

Исправление в `useFeatures` (`apps/web/src/lib/queries.ts`): во время гидратации флаги пустые, как
на сервере, после — действующие (`useSyncExternalStore` с серверным снимком). Защищает все места,
где флаги попадают в атрибуты: рейку, нижнюю навигацию, список проектов, рабочую область.

Тест `features-hydration.test.tsx` воспроизводит порядок «meta до гидратации»: без исправления
падает, с исправлением проходит.

### Среда e2e

Порт 3000 на этой машине занят сторонним приложением. Playwright с `reuseExistingServer`
переиспользовал чужой сервер, и первый прогон дал 47 ложных падений. Все прогоны выше —
на собственном сервере: `WEB_PORT=3100` либо `E2E_BASE_URL=http://127.0.0.1:3100`.
