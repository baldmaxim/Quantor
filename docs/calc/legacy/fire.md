# Старый портал: пожаротушение ВПВ и АУПТ

Каталог правил калькулятора пожаротушения старого портала — часть разбора PROMPT 00. Обзор,
легенда классов и действий — в [00-legacy-portal-analysis.md](../00-legacy-portal-analysis.md).

Файл: `public/fire-protection.html` в архиве старого портала вне git (скрипт — строки 363-2164).
Страница ничего не сохраняет, цен не содержит, итогов в портал не отправляет. Ссылки на ГОСТ есть
только в названиях изделий («указано в коде, не проверено»); комментарий «4 струи — требование для
вестибюля» документа не называет. Нормативных правил нет.

## Контрольный случай

B — 25 этажей, H = 75 м (h = 3,0), 2 секции, граница зон 17 (зона I — 17 этажей, зона II — 8),
2 стояка на зону, DN 65, коридор 30 м.

| Система | Результат старого портала                                                                                                                                                                                                                                                                                 |
| ------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ВПВ     | шкафы: 4 × ШПК-320-12, 64 + 32 × ШПК-320-21; огнетушителей 8; датчиков положения, рукавов и манометров по 100; диафрагм 52 + 32; стояков 102 + 150 м; ответвлений 102 + 48 м; грувлок-муфт 68 + 100; хомутов 136 + 132; заглушек 10; отводов 75 + 36; комплектов маркировки 21; окраска 76,1 м² → 30,4 кг |
| АУПТ    | спринклеров 306 + 144; сигнализаторов потока, затворов и промывочных кранов по 34 + 16; трубы DN 25 1020 + 480 м; стояков DN 80 102 + 48 м + транзит 102 м; грувлок-муфт 68 + 100; хомутов 748 + 420; шаровых кранов 4 + 4; узлов управления 2                                                            |

## Скрытые допущения

- Граница зон 17 этажей — общая для ВПВ и АУПТ.
- 2 шкафа на секцию на каждом этаже; 2 стояка на зону на корпус.
- Диафрагмы на нижних 13 этажах каждой зоны.
- Рукава DN 65, 20 м.
- 4 шкафа в вестибюле при любой ненулевой площади.
- АУПТ защищает только коридоры: один ряд спринклеров с шагом 3,5 м, коридор 30 м, коммерческий
  этаж не защищается; высота этажа по умолчанию 3 или 3,3 м.
- Расход краски 0,4 кг/м².
- Портал молча подставляет квартирографию другого проекта, если у текущего её нет.
