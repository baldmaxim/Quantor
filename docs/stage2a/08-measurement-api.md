# Промт 08 — API ручного обмера

Дата: 2026-09-09. Домен — [промт 07](07-takeoff-domain.md),
[ADR-0019](../adr/0019-takeoff-item-i-measurement.md).

## 1. Набор операций

Девять операций, не эндпоинт на поле:

```text
GET    /projects/{id}/takeoff-items          список строк, ?include_archived
POST   /projects/{id}/takeoff-items          создать строку
PATCH  /takeoff-items/{id}                   изменить описание
POST   /takeoff-items/{id}/archive           архивировать

GET    /sheets/{id}/measurements             измерения листа, ?takeoff_item_id
POST   /sheets/{id}/measurements             создать измерение
POST   /sheets/{id}/measurements/batch       пакет для счёта
PATCH  /measurements/{id}                    правка геометрии с версией
DELETE /measurements/{id}                    мягкое удаление
```

Всего в OpenAPI стало 61 операция. Клиент перегенерирован, ручных DTO нет.

## 2. Чтение по листу, а не по документу

`GET /sheets/{id}/measurements` возвращает измерения **одного листа**. Просмотрщик
показывает открытую страницу; тянуть измерения всех 77 листов ради одного — это тот же
N+1, только наоборот.

Обход по строкам закреплён тестом `test_measurement_list_does_not_grow_with_rows`: число
запросов на 23 измерениях равно числу на трёх.

Страницы у списков нет намеренно. Строк у проекта десятки, измерений на листе — сотни;
пагинация здесь была бы механикой без причины, а предел размера ответа держит предел
числа вершин у измерения (10 000) и предел пакета.

## 3. Пакет для счёта

Счёт ставит метки подряд, и ждать ответа сервера на каждый щелчок пользователь не должен.
Отсюда `POST /measurements/batch`.

**Пакет атомарен.** Одна негодная геометрия отменяет весь. Частичный результат заставил бы
клиента выяснять, какие из двадцати меток сохранились, — а он их уже нарисовал. Проверено
тестом: третья точка вне листа отменяет первые две.

**Предел 200 измерений** на пакет. Пакет без предела — способ положить сервер, а не
удобство.

## 4. Конкурентное редактирование

`PATCH /measurements/{id}` требует `version`. Клиент, открывший лист десять минут назад,
не перетирает чужую правку молча: расхождение — **409 `MEASUREMENT_VERSION_CONFLICT`**.

Проверено тестом: вторая правка с той же версией отвергается.

## 5. Злонамеренные сочетания

Каждое проверено тестом:

| Попытка                              | Ответ                                |
| ------------------------------------ | ------------------------------------ |
| строка проекта A на листе проекта B  | 422                                  |
| калибровка другого листа             | 422                                  |
| измерение чужого пространства        | **404**, не 403                      |
| лист чужого пространства             | 404                                  |
| архивная строка                      | 422                                  |
| `source: "ai"` через ручной эндпоинт | 201, но `source` в ответе — `manual` |
| читатель пишет                       | 403; чтение при этом 200             |

404 вместо 403 намеренно: 403 подтвердил бы существование объекта и превратил перебор
идентификаторов в разведку.

Подделка источника не отвергается, а **игнорируется**: поля просто нет в контракте, и
записать что-либо кроме `manual` через этот путь нельзя.

## 6. Журнал

Пишется завершённое действие, а не движение указателя.

Массив координат в журнал не кладётся: тысяча пар чисел раздула бы записи и ничего бы не
объяснила. Вместо него — **отпечаток геометрии** (16 символов от SHA-256) и число точек.
Этого хватает, чтобы понять, менялась ли геометрия и насколько.

У пакета в журнале сводка: сколько создано и какого типа, а не список из двухсот
идентификаторов. Журнал должен объяснять, а не хранить.
