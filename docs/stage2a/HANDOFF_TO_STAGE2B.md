# Передача из Stage 2A в Stage 2B

Дата: 2026-09-09. Состояние этапа: **не закрыт** — см. [16-acceptance.md](16-acceptance.md).

Документ описывает, что есть на самом деле, а не что планировалось.

## 1. Что действительно работает

| Возможность                                   | Состояние                                                     |
| --------------------------------------------- | ------------------------------------------------------------- |
| Каноническая геометрия страницы из PDF        | работает, проверено на 77 листах настоящего чертежа           |
| Преобразования координат                      | работает, сверено между Python и TypeScript точным равенством |
| Ручная калибровка масштаба                    | работает, версионная, с доказательством                       |
| Строки обмера и измерения                     | работают через API, покрыты тестами на базе                   |
| Инструменты Count / Line / Polyline / Polygon | работают в просмотрщике                                       |
| Расчёт count / length / area                  | работает, отдаётся через API с полным происхождением          |
| Показ величины                                | инспектор и итог по строке обмера                             |

Проверено полностью: 684 теста API, 286 web, 8 admin, ноль пропусков. Расчёт точен на 16
аналитических случаях, происхождение в ответе обязательно, сквозной путь от измерения до
величины проверен на живой базе.

## 2. Схема и миграции

Голова: `0010_takeoff_domain`. Цепочка линейна, оба направления разворачиваются.

| Миграция                   | Что добавила                                                             |
| -------------------------- | ------------------------------------------------------------------------ |
| `0007_job_workspace_scope` | `jobs.workspace_id`, CHECK области видимости, композитный ключ на проект |
| `0008_page_geometry`       | `page_geometry` — 1:1 с листом                                           |
| `0009_scale_calibration`   | `scale_calibrations` с доказательством и частичным уникальным индексом   |
| `0010_takeoff_domain`      | `takeoff_items`, `measurements`                                          |

Ключевые инварианты живут в базе, а не в сервисе:

- `ck_jobs_workspace_scope` — задание проекта без пространства непредставимо;
- `uq_scale_calibrations_default_per_sheet` — действующая калибровка у листа ровно одна;
- `ck_measurements_points_match_geometry` — число точек соответствует типу геометрии
  (`jsonb_array_length`);
- `ck_takeoff_items_unit_matches_geometry` — единица показа следует из типа.

## 3. Эндпоинты

Обмер (`app/api/v1/takeoff.py`):

```text
GET    /projects/{project_id}/takeoff-items
POST   /projects/{project_id}/takeoff-items
PATCH  /takeoff-items/{item_id}
POST   /takeoff-items/{item_id}/archive
GET    /sheets/{sheet_id}/measurements
POST   /sheets/{sheet_id}/measurements
POST   /sheets/{sheet_id}/measurements/batch
PATCH  /measurements/{measurement_id}
DELETE /measurements/{measurement_id}
GET    /sheets/{sheet_id}/quantities
```

Масштаб (`app/api/v1/scale.py`):

```text
GET   /sheets/{sheet_id}/scale-calibrations
POST  /sheets/{sheet_id}/scale-calibrations
GET   /scale-calibrations/{calibration_id}
POST  /scale-calibrations/{calibration_id}/default
POST  /scale-calibrations/{calibration_id}/verification
```

Величины отдаются одним запросом на лист. Один на измерение был бы тем же N+1, только со
стороны клиента: число запросов не зависит от числа измерений, и это проверено счётчиком.

Область указана в ответе — лист и ревизия. Итога по документу нет намеренно: он складывал бы
измерения разных ревизий и посчитал бы одни и те же двери дважды.

### Границы запроса

| Предел              | Значение                 |
| ------------------- | ------------------------ |
| Точек в измерении   | 10 000                   |
| Координат в точке   | ровно 2                  |
| Измерений в пакете  | 200                      |
| JSON-тело           | 4 МиБ                    |
| NaN и бесконечность | отвергаются на контракте |

Пределы стоят на схеме, а не только в сервисе: запрос, дошедший до сервиса, уже разобран и
оплачен памятью.

## 4. Права

| Право            | Кто имеет                                             |
| ---------------- | ----------------------------------------------------- |
| `takeoff.read`   | читатель и выше — величина без основания непроверяема |
| `takeoff.verify` | проверяющий и выше — подтверждать, но не вносить      |
| `takeoff.edit`   | инженер и выше                                        |

Разделение автора и проверяющего — смысл ролей, а не формальность. Чужой объект отвечает
**404**, а не 403: существование чужого листа тоже сведения.

## 5. Клавиатура и поведение

| Клавиша             | Действие                                                                               |
| ------------------- | -------------------------------------------------------------------------------------- |
| `Enter`             | завершить ломаную или многоугольник                                                    |
| `Backspace`         | убрать последнюю вершину черновика; при пустом черновике — удалить выбранное измерение |
| `Delete`            | удалить выбранное сохранённое измерение                                                |
| `Escape`            | отменить черновик                                                                      |
| `V`                 | режим выбора                                                                           |
| `Space` (удержание) | временное панорамирование любым инструментом                                           |

Счёт и линия завершаются сами: одна точка и две точки соответственно.

Жест не проходит через состояние React. Проверено: за 40 движений указателя — ноль коммитов
React, ноль перерисовок страницы PDF, ноль обращений к сети.

| -------------------- | -------: | -------: |

рабочих объёмах. Порядок при росте — пространственный индекс, уровни детализации, и только

## 7. Живая приёмка

Гейт `LIVE_PDF = PARTIAL`. Бланк: [live-acceptance.md](live-acceptance.md).

Шаги 1–4 закрыты на живом импорте эталона: 77 листов и 383 области, геометрию извлёк
**исполнитель**, а не API по ходу запроса, 77 строк `PageGeometry`, лист открывается.
Шаги 5–14 требуют человека у экрана с подписанным размером.

Что уже снято с настоящего чертежа: 77 страниц за 0,35 с, повороты только 0 и 90, повёрнутых
листов 47, на всех стороны отображения переставлены. Число 47 совпало с ADR-0008,
полученным другим путём.

Практическое следствие для того, кто будет мерить: на вписанном в экран листе точность
недостижима. A1 при 1:100 — это 35,3 мм на точку PDF, и один пиксель промаха стоит около
5 см. Мерить при увеличении, где пиксель не крупнее 10 мм.

## 8. Известные ограничения

1. **Живые шаги 5–14 не выполнены** — главное. Кода не требуется, требуется человек у
   экрана с подписанным размером на чертеже.
2. **Самопересекающиеся многоугольники** — формула шнурков даёт разность долей; «бантик»
   даёт ноль. Политики нет намеренно: правильный ответ зависит от того, что рисовал человек.
   Случай зафиксирован в датасете замера, чтобы смена поведения была заметной.
3. **Материализации величин нет** — считается по запросу. Снимки потребовали бы решать,
   когда пересчитывать и что делать со старыми при смене правила; данных для этого решения
   пока нет.
4. **Локальный масштаб (`scope_kind = region`)** объявлен в схеме, но не создаётся: узел
   1:20 на листе 1:100 не потребует миграции данных, когда до него дойдут руки.
5. **Попадание перебирает всё** — дорого от тысяч фигур. Сигнатуру функции менять не
   придётся.
6. **Память слоя не измерена** — браузер округляет `performance.memory`.
7. **`str_enum` обещает CHECK, которого не создаёт** — расхождение докстроки с поведением
   SQLAlchemy ≥ 1.4. Найдено на Stage 2A, не чинилось: затронет каждое перечисление.
8. **Корневой `README.md` устарел** — заявляет Stage 1.

## 9. Точка расширения для AI

Она уже есть и её не нужно проектировать заново.

`MeasurementSource` — перечисление с двумя значениями. Сейчас сервис ставит `MANUAL`
**жёстко**, параметром это не управляется: подделать источник из запроса нельзя, и тест
`test_source_cannot_be_forged` это стережёт.

Автоматический подсчёт Stage 2B создаёт **обычные** `Measurement` со значением
`MeasurementSource.AI`. Ничего другого: та же таблица, та же геометрия, та же калибровка, то
же правило расчёта. Отличие только в поле источника и в том, что у такого измерения впереди
проверка человеком — для неё уже есть `VerificationState` и право `takeoff.verify`.

Что для этого понадобится и чего пока нет:

- разрешить сервису принимать источник — но **только** из доверенного пути исполнителя, не
  из HTTP;
- шлюз моделей в runtime (`models.gateway`, объявлен, реализаций нет);
- признак того, кто именно распознал: модель и её версия, рядом с отпечатком входа — по
  образцу того, как калибровка хранит своё доказательство.

Величина при этом считается **тем же движком**. Если ручная линия на известном размере даёт
верные метры, то и линия от модели даст: разница в том, кто поставил точки, а не в том, как
из них получаются метры. В этом и был смысл порядка этапов.

## 10. Запреты, которые Stage 2B не обходит

Действуют по-прежнему:

- автоматическое определение масштаба, включая чтение надписи `М 1:100`;
- автоматическое распознавание размерных линий;
- семантические строительные правила и вычитание проёмов;
- объём, масса, стоимость;
- разбор BIM (RVT/NWD/NWC/IFC) — файлы только хранятся;
- ProjectGraph и агентный runtime;
- сметный движок и ВОР как рабочий отчёт;
- сравнение ревизий чертежа;
- молчаливое сложение измерений разных ревизий.

Отдельно: **величина, которую нельзя объяснить цепочкой измерение → лист → геометрия →
калибровка → правило, не показывается**. Для измерения от модели это правило то же самое,
и «модель так решила» объяснением не является.

## 11. Направление Stage 2B

```text
Только Auto Count
→ runtime шлюза моделей
→ локальные и внешние зрительные модели
→ сравнение детектора и VLM
→ модель создаёт обычный Measurement с source = ai
→ проверка и правка человеком
```

Это направление, а не план. Stage 2B начинается отдельным пакетом владельца.
