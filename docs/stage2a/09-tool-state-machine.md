# Промт 09 — машина состояний инструментов

Дата: 2026-09-09. `apps/web/src/lib/viewer/tool-machine.ts`.

## 1. Что это

Чистое ядро взаимодействия: не знает ни о DOM, ни о canvas, ни о сети, ни о TanStack Query.
На вход — смысловые события в нормализованных координатах, на выход — состояние черновика.

```text
setMode · pointerDown · pointerMove · finish · cancel · backspace
selectMeasurement · startVertexDrag · moveVertex · finishVertexDrag · setPanOverride
```

Переход — одна чистая функция `applyToolEvent(state, event)`. То же состояние и то же
событие всегда дают тот же результат, поэтому каждая ветка закрывается табличным тестом,
не поднимая браузер.

Разделение не косметическое: логика рисования — десяток переходов, каждый из которых можно
сломать, и проверять их в браузере вместе с отрисовкой и сетью почти невозможно.

## 2. Правила, которые она держит

| Режим                    | Поведение                             |
| ------------------------ | ------------------------------------- |
| `count`                  | завершается с первого щелчка          |
| `line`                   | завершается на втором                 |
| `polyline`               | завершение явное, минимум две вершины |
| `polygon`                | завершение явное, минимум три         |
| `select`, `pan`, `scale` | вершин не ставят вовсе                |

**Многоугольник не замыкается** дублированием первой вершины: замыкание — свойство типа,
а не данных (ADR-0019). Проверено тестом отдельно.

**Незавершаемая фигура не сбрасывается.** Нажатие «завершить» на двух вершинах
многоугольника ничего не делает: пользователь дощёлкивает недостающую, а не начинает заново.

**Смена инструмента отбрасывает черновик**, но не выбранное измерение: точки, поставленные
линией, ничего не значат для многоугольника, а выбор — это другое состояние.

**Пробел не ломает черновик.** Временное панорамирование — отдельный флаг, а не режим:
отпустив пробел, пользователь возвращается к своему инструменту с целым черновиком.

## 3. Что не попадает в черновик

- точки вне листа;
- `NaN` и бесконечность;
- повтор той же точки — дребезг, а не вершина;
- любые щелчки, пока зажат пробел.

Углы листа при этом допустимы: обмер по краю чертежа — обычное дело.

## 4. Перетаскивание вершины

Геометрия уходит наружу **один раз**, по отпусканию кнопки. Обращение к серверу на каждое
движение указателя превратило бы правку вершины в поток запросов — это закреплено тестом:
три движения дают ноль сигналов наружу, и только `finishVertexDrag` возвращает результат.

Отмена во время перетаскивания возвращает вершину на место: геометрия на сервере не
менялась, значит и на экране меняться не должна.

Вершину нельзя вытащить за пределы листа, а несуществующий индекс игнорируется.

## 5. Тесты

35 тестов, все табличные, ни одного снимка разметки. Снимок сказал бы «что-то отрисовалось»,
а нужно знать, что именно произошло с вершинами.

Покрыты все переходы, включая недопустимые последовательности: движение вершины без
начатого перетаскивания, завершение в режиме выбора, шаг назад в пустом черновике.
