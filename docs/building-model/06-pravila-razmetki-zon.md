# Правила разметки зон листа (вкладка CAD)

Зона (`cad_zones`) — разметка человека: эталон для движка CAD и вход будущего расчёта отделки, не измерение.
Правила выведены 2026-11-11 на пилотном листе (типовой этаж, секция с лестницей Н2, лифтовым холлом/ПБЗ,
тамбур-шлюзом и проходным лифтом) по разбору разметки МОП владельца и автоконтуров квартир.

## 1. Общие

1. Одна зона — одна строка экспликации. `room_mark` — марка из экспликации дословно (`3-1/2`, `3-3.1`),
   `name` — наименование из экспликации дословно (не «Тамбур», а «Тамбур-шлюз»; не «Лестницы», а
   «Лестничная клетка Н2»). У помещения квартиры `apartment_no` — номер квартиры из экспликации; у МОП — пусто.
2. Контур — по внутренней грани ограждения: край заливки стены, перегородки, монолита, колонны, короба шахты
   на плане АР. Не по оси, не по размерной линии, не по линии отделки.
3. Соседние зоны не перекрываются. Там, где помещения сообщаются (проём, условная граница), между ними нет щели:
   у обеих зон общая линия.
4. Шахты (ОВ, ВК, ЭО/СС, ДУ, КДУ, ПК) и лифтовые шахты не входят ни в одну зону, контур обходит их по граням.
5. Отверстий зона не держит: колонну или пилон у стены контур обходит. Отдельно стоящая колонна остаётся
   внутри зоны; её площадь (обычно до 0,25 м²) учитывается при проверке по экспликации.

## 2. Дверные проёмы

1. В проёме граница двух помещений — одна общая линия по полотну двери (линия коробки на плане).
2. Часть проёма от полотна до грани стены отходит помещению, которое находится с противоположной открыванию стороны.
   Помещение со стороны открывания доходит до полотна, а не останавливается на грани своей стены.
3. Двери лифтов: проём в стене шахты до линии двери лифта отходит площадке (лифтовой холл, тамбур).
   Шахта не относится ни к одной зоне.
4. Сама дверь — отдельная зона `door`: отрезок по линии полотна, высота проёма — из АР.

Типовая ошибка (найдена на пилоте): одна зона заходит в проём до полотна, а соседняя стоит на грани стены.
Остаётся щель около 70 мм (коридор ↔ лифтовой холл, коридор ↔ тамбур, тамбур ↔ лестница).

## 3. Стены МОП

1. Лестничная клетка — одна зона целиком: марши, площадки, промежуточная площадка, по граням стен клетки.
   Проём в тамбур — по разделу 2.
2. Лифтовой холл / ПБЗ — по граням стен. Проёмы лифтовых дверей включаются до линии дверей, стены шахт — граница.
3. Тамбур-шлюз — по граням стен. Проём в коридор, проём на лестницу и проём проходного лифта — по разделу 2.
4. Коридор — по граням стен от торца до торца. В проёмы квартирных дверей и дверей МОП — по разделу 2.
   Короба шахт в коридоре обходятся по граням.
5. Проходной лифт с дверями в холл и в тамбур эти зоны не объединяет: через шахту границы нет.

## 4. Помещения квартир

1. Перегородка между помещениями: каждая зона идёт по своей грани, толщина перегородки не входит ни в одну зону.
2. Открытая планировка (прихожая — кухня — коридор без стены): граница идёт по тонкой сплошной чёрной линии
   условной границы на АР. Зоны примыкают по ней без щели.
3. Наружная стена и остекление — по внутренней грани. На криволинейном фасаде — ломаная по дуге
   с шагом 150–300 мм.
4. Гардеробная, постирочная, ниша — отдельные зоны по своей марке.

## 5. Проверка по экспликации

- МОП: площадь зоны по граням минус отделочный слой 20 мм на каждую грань ≈ площадь экспликации
  (для прямоугольника `(a − 0,04)·(b − 0,04)`). Допуск ±1 %. На пилоте у трёх помещений МОП расхождение ≤ 0,03 м².
- Квартиры: площадь зоны по граням ≈ площадь экспликации. Допуск ±5 % на помещение, ±3 % на квартиру
  (на пилоте квартиры дали от +0,1 до +2,5 %).
- Перед проверкой из площади вычитаются заходы в проёмы.
- Если расхождение больше допуска: сначала проверить калибровку листа, затем проёмы, колонны и условные границы.

## 6. Автоконтуры квартир (пилот)

Помещения квартир пилотного листа размечены автоматически: детектор помещений `tools/cad_mep` (растр стен
и барьеры дверей). Затем доработка:
- разбиение открытых планировок по линиям условных границ;
- рост до граней стен и остекления на растре 5 мм;
- дуга фасада.

Метаданные (`apartment_no`, `room_mark`, `name`) взяты из экспликации листа. Это кандидат для проверки
человеком: зоны правятся во вкладке CAD, как ручные. Генератор — `tools/cad_mep/run_zones.py`
(схема `quantor.cad_mep.zones.v1`, входы как у генератора трасс). Запуск из портала и загрузка зон оттуда — отдельным
решением.

## 7. Привязка при ручной разметке

Точка зоны прилипает к вершине (приоритет) или ребру соседних зон листа и к своим вершинам в радиусе 10 px.
Shift — горизонталь или вертикаль от предыдущей точки, Alt — без привязки. Привязка к углам и граням стен — следующий шаг.
