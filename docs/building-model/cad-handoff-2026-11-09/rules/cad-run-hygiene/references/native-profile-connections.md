# Связь настоящих профильных опор одной native-линией

Использовать как отдельное строгое семейство исходных свидетельств, когда прежний поиск требует несколько продольных линий или отдельный замкнутый PDF-subpath и потому не даёт сертификат. Не ослаблять глобальный оконный шаблон. Результат этого семейства — профильная связь с неизвестным заполнением и ролью, не принятое окно/стекло.

1. Извлечь заново исходные native штрихи, реальные fill/clip и источник масштаба. Готовые GZ/CAD читать только после исходного распознавания для сравнения вывода; пилот не является входом. Зафиксировать source/crop/rotation/scale/code SHA.
2. Собрать настоящие замкнутые многосоставные профильные циклы из фактических штрихов без snapping, buffer-закрытия или заполнения разрыва. Простой прямоугольник и одна линия не являются сложной профильной опорой.
3. Для каждого ребра доказать native-интервалы на исходных сегментах, а для положительного реального примера повторно проверить исходные PDF-операторы. Для повёрнутых координат разрешён лишь ULP-бюджет арифметического доказательства; геометрия и топология не расширяются. Малый реальный разрыв по-прежнему разрывает цикл.
4. Найти полную настоящую линию с фактическими контактами у двух независимых опор. Проверить зеркальное соответствие сложных опор в пределах доказанной точности источника. Не создавать отсутствующую вторую грань и не брать соседнюю параллельную линию, которая не касается этих опор.
5. Оpaque/native hatch, чёрные диагонали, периодические ламели и исходные swing/door источники дают отказ либо сохраняют неустановленную роль. Контекстная оболочка служит только отрицательной проверке: её не выводить как границу окна или материал.
6. Положительную связь выводить отдельным диагностическим классом infill_unknown. Единственная соединительная линия не доказывает стекло, изделие, фиксированную/открывающуюся роль, высоту или количество окон.
7. Нормализовать физические native-интервалы с alias/owner/t. Общая рамная часть хранится один раз, существующий владелец — отдельная ссылка. Длинный parent part не захватывать целиком. Legacy overlap положительной длины блокирует интеграцию. Проверить новые/новые и новые/старые интервалы независимым способом.

Не расширять отбор по RGB автоматически: настоящая тонкая белая полоса с серыми границами может иметь скошенные торцы и реальные возвратные профили. Такие загнутые полосы/панели остаются другим графическим семейством; нельзя превращать их в прямоугольное стекло или закрывать соседний реальный зазор.

Проверки: обе настоящие опоры плюс одна native-линия; удалённое ребро и микрогап без заделки; несогласованные опоры; чужая параллельная линия; непрозрачное/штрихованное заполнение, ламели, двери/дуги; изменение source-ID/порядка, поворот/перенос/единиц; source-interval alias, частичное покрытие, длинный parent и блокировка старого дубля. Успех этой стадии не закрывает production-задачу или пользовательскую отметку.
