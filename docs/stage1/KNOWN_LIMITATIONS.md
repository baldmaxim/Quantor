# Известные ограничения после промта 02

Список ведётся честно: это не ошибки, а осознанно отложенное или непроверенное.

## Не реализовано (по плану этапа)

- Доменные таблицы и API проектов — промт 03. Alembic работает, но миграций с таблицами нет.
- `ObjectStorage` умеет только проверять доступность бакета. Потоковая загрузка, presigned URL,
  `stat` и удаление появятся вместе с первыми потребителями (промт 03).
- Загрузка файлов, импорт распознанного пакета, просмотрщик, оболочка рабочей области —
  промты 05–07.
- Аутентификации нет: портал работает в dev-режиме без пользователей и разграничения доступа.
  Наружу в таком виде выставлять нельзя.
- Очередей и воркеров нет. Задания появятся вместе с реальной нагрузкой ([ADR-0005](../adr/0005-abstrakciya-zadanij.md)).

## Проверено не полностью

- Подъём контейнеров, миграции на живой базе и `/health/ready` со статусом `ok` не выполнялись
  на машине разработки — там не запущен Docker. Проверяются на тестовом компьютере по
  инструкции из [README](../../README.md).
- Playwright-сценарии написаны, но браузеры не установлены (`pnpm exec playwright install`).
- Образы `minio/minio:latest` и `minio/mc:latest` не закреплены по версии: на момент работы
  не было надёжного способа выбрать актуальный тег `RELEASE.*`. Закрепить при первом
  боевом развёртывании.

## Технические компромиссы

- `exactOptionalPropertyTypes` в TypeScript выключен: сгенерированный клиент API под него не
  написан, а править генерируемый код нельзя. Остальная строгость сохранена.
- Правила `ruff` `RUF001–RUF003` (неоднозначные символы) выключены — документация на русском.
- Версии зависимостей Python закреплены точно, без lock-файла ([ADR-0009](../adr/0009-python-i-lokalnyj-tuling.md)).
- Долгие операции пока выполняются в процессе API: при многопользовательской нагрузке
  потребуется вынести их в воркер.
