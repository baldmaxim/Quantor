# Известные ограничения Stage 1

Список ведётся честно: это не ошибки, а осознанно отложенное или непроверенное.
Обновлён 2026-09-07, после сквозного прогона на эталонном пакете.

## Не реализовано (границы этапа)

Запрещено правилами этапа и намеренно отсутствует — см. `CLAUDE.md`:

- распознавание элементов, Auto Measure / Auto Count, определение масштаба чертежа;
- вычисление длин, площадей и объёмов как рабочая функция;
- инференс CV/LLM/VLM — контракты описаны ([ADR-0006](../adr/0006-shlyuz-modelej.md)),
  вызовов нет;
- извлечение данных из BIM: RVT/NWD/NWC/IFC принимаются на хранение и не разбираются;
- сметный движок и отчёты ВОР как рабочий расчёт.

Отложено по инженерным причинам:

- **Аутентификации нет.** Портал работает в dev-режиме, `workspace_id` фиксирован.
  Наружу в таком виде выставлять нельзя — это главное ограничение этапа.
- **Очередей и воркеров нет.** Импорт выполняется внутри процесса API
  ([ADR-0005](../adr/0005-abstrakciya-zadanij.md)). Один пакет — 1,5 с; при нескольких
  одновременных займёт рабочие потоки приложения.
- **Сравнения ревизий чертежа нет** даже заглушкой: по флагам это `drawing.compare`
  уровня «позже», место под него в макете не резервировалось.
- **Поиска по распознанному тексту нет.** Работает поиск по текстовому слою PDF; поиск
  по `raw_content_md` областей потребует индекса на стороне API.

## Проверено не полностью

- **Профилирование памяти не делалось.** Пиковая RSS процесса API при импорте 47 МБ,
  FPS при панорамировании и переключение слоя из 383 областей не замерялись —
  см. [отчёт](performance-security-report.md).
- **Установка PWA на реальных устройствах не проверена.** Прогоны идут в WebKit и
  Chromium из Playwright; ярлык на настоящем iPhone и Android, поведение
  `position: fixed` с открытой клавиатурой нужно посмотреть руками.
- **Образы `minio/minio:latest` и `minio/mc:latest` не закреплены по версии**: на момент
  работы не было надёжного способа выбрать актуальный тег `RELEASE.*`. Закрепить при
  первом боевом развёртывании.
- **Тесты базы данных пропускаются без PostgreSQL.** На машине разработки Docker не
  поднимается, поэтому 79 тестов там пропускаются; на тестовой машине проходят все 246.
  Пропуск в CI считается ошибкой сборки.
- **Дедупликация при одновременной загрузке одного файла дважды** не проверена: очередь
  грузит файлы последовательно, но при параллельной загрузке обе проверки по SHA-256
  могут не найти ещё не зафиксированную ревизию и создать два документа.

## Технические компромиссы

- `exactOptionalPropertyTypes` в TypeScript выключен: сгенерированный клиент API под него
  не написан, а править генерируемый код нельзя. Остальная строгость сохранена.
- Правила `ruff` `RUF001–RUF003` (неоднозначные символы) выключены — документация на русском.
- Версии зависимостей Python закреплены точно, без lock-файла
  ([ADR-0009](../adr/0009-python-i-lokalnyj-tuling.md)).
- `Job.id` — uuid4. Тай-брейкер «последнего задания» по `id` делает выборку
  детерминированной, но не «самой поздней» при совпадающем `created_at`. Настоящий
  порядок потребует монотонного ключа (uuid7 или sequence).
- `created_at` заданий ставит приложение, а не БД: `now()` в PostgreSQL одинаков внутри
  транзакции. При нескольких процессах API порядок начнёт зависеть от расхождения часов.
- Рамки контролов в тёмной теме мягче порога 3:1 по требованию владельца продукта.
  Индикатор фокуса контрастный (6,4:1) — на нём компромисса нет.
- В хранилище PDF эталонного пакета лежит дважды: внутри архива и отдельным документом
  после импорта. Это цена неизменяемости исходника ([ADR-0003](../adr/0003-neizmenyaemye-revizii.md)).
