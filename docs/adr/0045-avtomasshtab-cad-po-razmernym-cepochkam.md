# ADR-0045. Автомасштаб CAD по размерным цепочкам для листов без калибровки

Дата: 2026-11-11
Статус: принято владельцем 2026-11-11

## Контекст

Преобразование PDF → DXF (ADR-0036) требовало действующей калибровки каждого выбранного листа (ADR-0018):
без неё постановка отвечала 409 `CAD_CALIBRATION_REQUIRED`. Для массового запуска по всем листам-планам ревизии
калибровать каждый лист вручную долго, при этом движок и так проверяет масштаб по размерным цепочкам векторов
PDF (подбор и независимая проверка на отложенных цепочках, `scale.json`).

## Решение

1. В контуре CAD при отсутствии калибровки человека масштаб листа определяет движок по размерным цепочкам.
   Постановка принимает `auto_scale: true`; калиброванные листы по-прежнему идут по масштабу человека, при
   `auto_scale: false` лист без калибровки даёт прежний 409.
2. Принимается только итог `dimension_checks_passed` с источником `dimension_chains`. Статусы `needs_review`,
   `printed_scale_only`, `failed`, отсутствие вида или `scale.json` масштаб не подтверждают.
3. Надпись «М 1:NN» масштабом не служит никогда (ADR-0018): она остаётся только контролем согласия с размерами.
4. Не подтверждён — задание падает с кодом `CAD_AUTO_SCALE_UNCONFIRMED`: «Масштаб листа не подтверждён размерами
   чертежа — откалибруйте лист вручную и преобразуйте заново». Повтор того же задания даст тот же отказ; после
   калибровки параметры меняются (калибровка входит в них), и задание ставится заново.
5. `ScaleCalibration` при автомасштабе не создаётся. Ручной обмер, площади зон и calc по-прежнему требуют
   калибровки человека; автомасштаб живёт только в результате преобразования (`scale.json`, кадр DXF → PDF).
6. В параметрах движка такая страница помечена `{"auto": true}` вместо `mm_per_pt` и `calibration_id`, поэтому
   ключ идемпотентности различает способ масштаба. Версия движка не меняется; runner не передаёт движку
   `operator_scales` для таких страниц, и движок идёт по размерным цепочкам.
7. Конвейер ревизии показывает все листы, чьё название (штамп, а без него подпись страницы) содержит слово
   «план», даже без работы; у листа есть `title`, `is_plan` и `scale_source` (`calibration` | `auto`).

## Последствия

- Последующие задания (`cad_walls`, `cad_zones`, трассы, 3D DXF этажа) берут масштаб из `scale.json` и кадра
  результата преобразования, а не из `ScaleCalibration`; менять их не потребовалось.
- Результат автомасштаба — кандидат, как и любой результат CAD: проверка инженером обязательна.
- Уточняет ADR-0018 и ADR-0036 п. 4 (масштаб по надписи по-прежнему запрещён).
