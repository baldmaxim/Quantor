# ADR-0054. Вход ИИ-чатов в MCP портала по OAuth 2.1

Статус: принято, 2026-11-18 (решение владельца: «давай начинай OAuth для веб-чатов»). Дополняет ADR-0051.

## Контекст

MCP-сервер портала (`POST /api/v1/mcp`) пускал только по личному токену `qtk_`: так подключаются
Claude Code и скрипты. Веб-чаты (Claude в браузере и в приложении, ChatGPT) внешние MCP-серверы
подключают только через вход по OAuth: человек нажимает «Подключить», чат открывает страницу сервиса,
человек разрешает доступ. Без этого десять проектировщиков в своих чатах портал не видят.

## Решение

1. **Портал сам — сервер входа**, без внешнего провайдера. Издатель — `portal_base_url`. Метаданные:
   `/.well-known/oauth-authorization-server` (RFC 8414) и `/.well-known/oauth-protected-resource/api/v1/mcp`
   (RFC 9728); их знает API (`/api/v1/auth/oauth/metadata/*`), сервер страниц пересылает. Отказ MCP без
   входа — 401 с `WWW-Authenticate: Bearer resource_metadata="…"`.
2. **Регистрация чата** — RFC 7591 (`/api/v1/auth/oauth/register`), открытая, но адреса возврата только из
   белого списка настроек `oauth_redirect_uris` (возврат Claude и ChatGPT) и адреса этого компьютера
   (`http://localhost`, флаг `oauth_allow_loopback`) — иначе любой сайт мог бы показать человеку страницу
   согласия портала и увести код. Документы клиента по адресу (CIMD) не объявлены: портал наружу не
   ходит, а оба чата при отсутствии CIMD регистрируются сами.
3. **Согласие** — страница `/oauth/authorize`, только сеанс портала: имя чата, куда уйдёт ответ,
   пространство, области (`read` всегда, `upload` — по выбору человека). Разрешение — строка `api_tokens`
   с `oauth_client_id`: тот же список «Доступ», тот же отзыв, права — роль владельца ∩ области.
4. **Значения** — код 5 минут, PKCE S256 обязателен, `iss` в ответе (RFC 9207), `resource` только адрес
   MCP (RFC 8707); доступ `qoa_` — час; обновление `qor_` — 30 дней, одноразовое, с заменой. Повтор кода
   или уже обменянного обновления (позже 60 с — не гонка) отзывает разрешение. В базе только sha256.
5. **Доступ чата — только MCP**: снаружи он принимается одним адресом `/api/v1/mcp`, внутри — вызовами
   инструментов MCP с секретом процесса. Остальной API отвечает ему 401.
6. Точки регистрации и выдачи лежат под `/api/v1/auth/` — под тем же пределом частоты nginx, что вход
   по паролю.

## Последствия

- Подключение: в чате — адрес `https://quantor.meridianai.ru/api/v1/mcp`, дальше вход и «Разрешить»
  ([docs/agent-api.md](../agent-api.md)).
- Миграция `0047_oauth`: `oauth_clients`, `oauth_tokens`, `api_tokens.oauth_client_id`. Откат удаляет их и
  строки разрешений чатам; личные токены `qtk_` не затронуты.
- Новый адрес возврата чата (сменился у Claude или ChatGPT) — правка настройки `oauth_redirect_uris`,
  без выпуска.
