# ADR-0000. Отступление от общего стека каталога Odintsov

Статус: принято, 2026-09-04

## Контекст

`Odintsov/CLAUDE.md` задаёт стек по умолчанию: React + Vite на фронтенде, Express + TypeScript
на бэкенде, `pg`-Pool без ORM. Он же разрешает отступать при наличии причин.

Quantor решает две задачи, нетипичные для остальных проектов каталога:

1. Просмотр PDF проектной документации на 50–500 МБ с наложением тысяч распознанных областей.
   Это требует `pdf.js` и WebGL-слоя с ручным управлением кадрами.
2. Потоковый разбор недоверенных ZIP-архивов распознавалки: защита от zip-бомб и path traversal,
   вычисление SHA-256 без загрузки файла в память, работа с кириллическими именами.

Вторая задача на Node решается заметно большим объёмом ручного кода, чем на Python, где
`zipfile`, потоковая работа с файлами и типизированные Pydantic-валидаторы дают то же самое
меньшими средствами. Prompt-pack Stage 1 (`_prompts/stage1/`) спроектирован под Next.js + FastAPI:
его ADR, acceptance-критерии и промты 02–10 предполагают именно этот стек.

## Решение

Для Quantor берём стек из prompt-pack:

- фронтенд — Next.js (App Router) + React + TypeScript strict, Tailwind, TanStack Query;
- бэкенд — Python 3.12 + FastAPI + Pydantic v2 + SQLAlchemy 2 async + Alembic.

Остальные правила `Odintsov/CLAUDE.md` остаются в силе без изменений: ответы и документация
на русском, строгая типизация, запрет `any`, темы через токены, адаптивность, работа с `.env`.

## Последствия

- В репозитории два языка; разработчику нужны и Node, и Python. Команда `pnpm run setup`
  готовит оба окружения, чтобы это не превратилось в ручную возню.
- Контракт API не дублируется вручную: TypeScript-типы генерируются из OpenAPI
  (см. [ADR-0001](0001-granicy-monorepozitoriya.md)).
- Код нельзя переиспользовать с FOT/HUBTender напрямую. Потери невелики: общего домена нет.
- Tailwind вместо CSS Modules — отступление внутри отступления, продиктованное тем же пакетом
  и плотными инженерными интерфейсами. Цвета всё равно берутся только из токенов.

## Отвергнутые альтернативы

- **Vite + Express по общему стеку.** Пришлось бы переписать половину prompt-pack и вручную
  реализовать потоковую безопасную распаковку. Выигрыш — единый язык — не окупает риск в той
  части, которая обрабатывает недоверенный ввод.
- **Гибрид: Vite-фронтенд + FastAPI-бэкенд.** Убирает Next.js, но расходится с промтами 02/04
  и лишает маршрутизации и серверных компонентов, которые пригодятся для тяжёлой рабочей области.
