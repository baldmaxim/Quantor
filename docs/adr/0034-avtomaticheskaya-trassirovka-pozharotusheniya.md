# ADR-0034. Автоматическая трассировка пожаротушения: кандидаты геометрии и трасс в исполнителе заданий

Статус: принято, 2026-10-19, решением владельца. Уточняет
[ADR-0033](0033-pozharotushenie-v-raschyotnom-konture.md): снимает запрет «трассировка сетей
автостоянки и листы разводки в портале» в части трасс, остальное в ADR-0033 действует. Контур `calc`
([ADR-0030](0030-raschyotnyj-kontur-stadii-p.md)) не меняется: он не читает PDF, не трассирует и
считает только по фактам. Следует [ADR-0008](0008-koordinaty-i-proishozhdenie.md),
[ADR-0014](0014-otdelnyj-ispolnitel-zadanij.md), [ADR-0015](0015-sloi-nalozheniya-na-canvas2d.md),
[ADR-0016](0016-kanonicheskaya-geometriya-stranicy-pdf.md),
[ADR-0018](0018-kalibrovka-masshtaba-cherteja.md) и
[ADR-0022](0022-kandidat-predskazaniya-otdelyon-ot-izmereniya.md).

## Контекст

После разбора навыка (промт F00, [карта переноса](../calc/fire/00-skill-transfer-map.md)) владелец
решил: построение трасс в портале должно быть автоматическим, как в навыке, а не ручным. В навыке
автоматически работают замер коридоров по плану АР, сетка оросителей торговли и трассировка
автостоянки (сетка распылителей, сеть с обходом стен, диаметры по нагрузке, кольца, завесы
электромобилей, кольцо ВПВ); разводку типового этажа навык рисует по конфигу, который составляет
человек.

ADR-0033 оставил трассировку в навыке, потому что навык:

- растрирует планы через PyMuPDF — библиотека отклонена ADR-0016 из-за AGPL;
- ищет помещения и стены по цвету пикселей — растр и детекторы запрещены в контуре calc;
- сам определяет масштаб по размерной цепочке — запрещено `CLAUDE.md`; на эталонном объекте
  автомасштаб одного корпуса ошибся почти вдвое.

В Quantor уже есть: исходный PDF ревизии в хранилище, разбор страниц через pypdf (ADR-0016),
калибровка листа человеком (ADR-0018, флаг `takeoff.manual`), отдельный процесс исполнителя заданий
(ADR-0014), слои наложения Canvas2D в рабочей области (ADR-0015). Планы АР стадии П, выгруженные из
САПР, — векторные: помещения — заливки, стены — пути, номера помещений и подписи шахт — текст.

Решения владельца при принятии:

1. Масштаб — только калибровка человеком; портал сам проверяет её по площадям помещений.
2. Трассировка — в исполнителе заданий портала, кандидатами с проверкой человеком.
3. Подсчёт значков на схемах ИОС2.2 — позже, отдельным промтом.

## Решение

Автоматическая трассировка — **генератор кандидатов геометрии и трасс**, отдельный от контура
`calc`, исполняемый только процессом `python -m app.worker`. Человек принимает кандидата; принятое
становится фактами реестра; `calc` считает по фактам, как раньше.

```text
PDF листа АР + калибровка (человек) + принятые факты + утверждённые правила
→ задание генератора (исполнитель) → кандидат листа: геометрия, трассы, проверки
→ наложение на плане в рабочей области → принять / отклонить (человек)
→ факты реестра → calc (детерминированный расчёт) → паспорт
```

| Ось              | Решение                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Код              | отдельный модуль сервисов (имя — в F01) вне `services/calc`; новый тип задания; модуль импортирует только исполнитель — процесс API и `calc` его не импортируют (страж-тест)                                                                                                                                                                                                                                                                            |
| Вход             | исходный PDF ревизии из хранилища, лист, утверждённая калибровка листа, принятые факты (экспликация, назначение помещений, шаг и отступ, Ду), утверждённые версии правил трассировки                                                                                                                                                                                                                                                                    |
| Геометрия        | только векторная: пути, заливки и текст с координатами из содержимого страницы через pypdf. Растр страницы, OCR, PyMuPDF, OpenCV, Shapely, pypdfium2 не используются. Лист без векторной геометрии (скан) — «автоматически не построено», резерв — ручной ввод и обмер                                                                                                                                                                                  |
| Масштаб          | только калибровка человеком (ADR-0018); автоопределение по-прежнему запрещено. Автопроверка: площади найденных помещений против экспликации; расхождение больше допуска — предупреждение, грубое — запуск BLOCKED с причиной «проверьте калибровку»                                                                                                                                                                                                     |
| Что строит       | геометрия листа: помещения с номером и площадью, стены и проёмы, отрезки коридоров, шахты «ПТ», места ЭМ. Трассы: этаж (оросители по оси отрезка, отвод от шахты, рядки с Ду), торговля (сетка, рядки, коллекторы, магистраль), автостоянка (сетка распылителей, сеть с обходом стен, диаметры по нагрузке, кольца, завесы ЭМ, кольцо ВПВ, шкафы по досягаемости по пути)                                                                               |
| Инженерные числа | только из утверждённых версий правил и фактов (шаг, отступ, диаметры по нагрузке, расход дренчера, длина рукава); без них запуск BLOCKED с перечнем недостающего                                                                                                                                                                                                                                                                                        |
| Веса алгоритма   | цена стены, чужого помещения, поворота, вес глубины, порог замыкания колец — часть версии алгоритма: в коде, с отпечатком, запоминаются запуском; это не инженерное число и не правило реестра                                                                                                                                                                                                                                                          |
| Варианты         | для этажа — не меньше двух вариантов разводки с числами (урок 32 навыка); вариант с красным флагом (труба через холл, ПБЗ, лестницу или квартиру; Ду больше гидрорасчёта; подводка длиннее отрезка; шахт «ПТ» больше групп стояков схемы) к принятию не предлагается без решения человека                                                                                                                                                               |
| Результат        | неизменяемый запуск генератора с отпечатками входа (PDF, калибровка, факты, версии правил, версия алгоритма) и кандидатом листа в JSONB: элементы с координатами, нормализованными от левого верхнего угла (ADR-0008), длины, Ду, фитинги, проверки. Отдельная сущность: ≠ `Measurement` ≠ `PredictionCandidate` ≠ факт реестра                                                                                                                         |
| Проверка         | кандидат показывается слоем Canvas2D на листе в рабочей области; человек принимает или отклоняет лист целиком с причиной. Правка отдельных элементов — не в первой версии: отклонить и поменять входы или параметры                                                                                                                                                                                                                                     |
| Принятие         | доверенный сервис пишет факты. Геометрия АР (длины отрезков, площади и размеры помещений, шахты, периметры рядов ЭМ) — метод `GEOMETRY_MEASURED`. Итоги трассы (длины по Ду и классам, фитинги, распылители, дренчеры, шкафы по досягаемости) — новый метод «по принятой трассе» (имя — F01): это предложение разводки, а не измерение чертежа. Свидетельство — принятый кандидат (новый вид свидетельства). Ручной HTTP-ввод этих методов не принимает |
| Расчёт           | `calc` читает только факты: итоги трассы — в EXPECTED; MINIMUM и резерв без трассы — формулы и удельные показатели правил; расхождение «по формулам» и «по трассе» больше допуска — предупреждение паспорта                                                                                                                                                                                                                                             |
| Флаги            | `calc.portal` и `takeoff.manual` (калибровка) — оба; проверка и в интерфейсе, и на сервере (ADR-0023)                                                                                                                                                                                                                                                                                                                                                   |
| Зависимости      | pypdf (уже есть); numpy (BSD-3) — для сеток и поиска пути, только в исполнителе; лицензия сверяется при добавлении                                                                                                                                                                                                                                                                                                                                      |

Разрешено **только за флагами** `calc.portal` и `takeoff.manual`: генератор кандидатов геометрии и
трасс пожаротушения в исполнителе, слой кандидатов в рабочей области, принятие кандидата в факты.

Запрещено и после этого решения:

- растр страницы, OCR, PyMuPDF, OpenCV, Shapely, pypdfium2 в `apps/api` (pypdfium2 для сканов — только
  отдельным решением после лицензии);
- автоматическое определение масштаба, в том числе по размерной цепочке и надписи «М 1:100»;
- разбор PDF и трассировка внутри `calc`; вход `calc` — только факты;
- кандидат в расчёте без принятия человеком;
- инженерное число в коде генератора;
- запись генератора в таблицы обмера, MEP и `Region`;
- копирование скриптов навыка: алгоритмы переписываются на векторной геометрии, данные объекта
  339 в git не попадают;
- подсчёт значков схем ИОС2.2 до отдельного промта F13 и решения владельца.

## Последствия

- Появляются тип задания, таблицы запусков генератора (миграция в промте реализации), слой
  кандидатов в просмотрщике и синтетические векторные PDF в тестах.
- Пакет промтов длиннее на три промта; гейт пожаротушения проверяет и автоматическую геометрию, и
  трассы — сверкой с результатами навыка на объекте 339 вне git.
- Калибровка листа становится обязательным шагом расчёта пожаротушения; без флага `takeoff.manual`
  остаётся ручной ввод.
- Скан вместо векторного плана автоматизацию отключает честно: «автоматически не построено».
- Точность автостоянки выше, чем у удельных показателей ADR-0033: EXPECTED — по принятой трассе,
  удельные показатели — только MINIMUM и резерв.

## Отвергнутые альтернативы

- **Растр страницы через pypdfium2 сейчас.** Лицензия в матрице — `conditional`, растр в `apps/api`
  запрещён; векторной геометрии планов из САПР достаточно. Для сканов — отдельное решение.
- **PyMuPDF, как в навыке.** Отклонён ADR-0016 (AGPL).
- **Автоматический масштаб с подтверждением.** Владелец оставил запрет: автомасштаб навыка ошибался;
  калибровка — два клика на лист, автопроверка по площадям ловит ошибку.
- **Трассировка внутри `calc`.** Ядро не читает документы (ADR-0030); геометрия — не скаляр факта.
- **Трассировка в процессе API.** Минуты счёта занимали бы рабочие потоки (ADR-0014).
- **Офлайн в `vision/`.** Не автоматически в интерфейсе — владелец выбрал исполнитель портала.
- **`Measurement(source=ai)` для трасс.** Путь ИИ закрыт до PASS Prompt 18; трасса — предложение
  разводки, а не измерение чертежа.
- **Ручная правка элементов кандидата в первой версии.** Сложный редактор; отклонение и смена входов
  покрывают первую версию.
