# ADR-0040. Материал конструкций из условных обозначений листа и каркасные перегородки в пилоте CAD

- Статус: принято (решение владельца 2026-11-11)
- Дополняет: [ADR-0038](0038-podschyot-kladki-i-monolita-v-pilote-cad.md), [ADR-0036](0036-pilot-cad-v-boyu-i-3d-dxf.md)

## Контекст

Тип стены для подсчёта — толщина и материал. Толщину `tools/cad_walls` выводит из геометрии заливок DXF
и привязывает к номиналу (ADR-0038). Материал по ADR-0038 вводит только человек.

На реальных листах АР штриховки разных материалов кладки одинаковы, но в условных обозначениях листа
материал указан вместе с толщиной («стены из … блоков N мм»). Владелец: данные, которые есть на чертеже,
человек вводить не должен. Каркасные перегородки из ГКЛ (система С112) движок кладёт на свои слои `07_C112_*`,
а `cad_walls` их не считает.

## Решение

1. Исполнитель CAD (`tools/cad_walls`, модуль `legend.py`) читает условные обозначения из **текстового слоя**
   исходного PDF: без OCR, без растра, без модели. Строка с материалом и толщиной даёт пару «номинал → материал»,
   строка «монолит/железобетон» — материал монолита.
2. Конструкция получает в `walls.json` необязательное поле `material_hint` — {`value` (коды `CadMaterial`),
   `source: "legend"`, `status`, `evidence` — текст строки, страница, рамка}. В параметры человека (props) подсказка
   не пишется: API показывает её как значение по умолчанию с источником «документ», пока человек не задал своё.
3. «Проверить» (подсказки нет, `value = null`): толщины нет в обозначениях (`not_in_legend`); у одной толщины два
   материала (`conflict`); обозначений на листе нет (`no_legend`). «Кирпич» без уточнения материала не даёт.
4. Каркасные перегородки С112 — новый вид конструкции `frame_partition`: контур из слоёв `07_C112_*`
   (обшивки и каркасная зона одной перегородки объединяются), толщина из геометрии с привязкой к номиналам.
   Изменения только аддитивные: id и поля существующих конструкций не меняются.

## Последствия

- Для уже распознанных листов перераспознавание не нужно: подсказки и С112 строятся по существующему DXF и PDF
  новой версией генератора `cad_walls`.
- Подключение в конвейер, параметры, версию генератора, контракт API (`kind`) и интерфейс — отдельными шагами
  по готовности параллельных правок трека ADR-0038/0039.
- Расхождения обозначений с нормами (например, ГОСТ, не относящийся к материалу) — вопрос к проектировщику,
  подсказку не меняют.
