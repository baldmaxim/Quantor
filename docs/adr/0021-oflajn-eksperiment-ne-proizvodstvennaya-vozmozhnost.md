# ADR-0021. Офлайн-эксперимент не является производственной возможностью

Статус: принято, 2026-09-11

## Контекст

Stage 2B обучает и сравнивает модели. Эксперименту нужно то, чего в производстве быть не должно:
частные клиентские данные, тяжёлые зависимости (PyTorch, SAM, Transformers, Unsloth), GPU и
свобода менять гиперпараметры.

Если это просочится в портал, удачный прогон на рабочей станции станет функцией раньше, чем его
проверили, а `apps/api` обрастёт стеком, который производственному процессу не нужен.

## Решение

Лаборатория и портал разделены по пяти осям.

| Ось       | Лаборатория                                                                     | Портал                                                                                   |
| --------- | ------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| Код       | отдельный Python-проект `vision/` со своим окружением и extras для обучения     | `apps/api` без torch, SAM, OpenCV, Transformers и Unsloth — это стережёт тест контрактов |
| Данные    | частный dataset root вне git, путь задаёт владелец; в git — только синтетика    | объектное хранилище портала                                                              |
| Результат | прогон с происхождением: отпечаток датасета, хеш разбиения, хеши весов, конфиги | только промотированный pipeline по явному идентификатору                                 |
| Решение   | единый QTO-бенчмарк с гейтами, объявленными до теста                            | утверждение владельцем конкретного pipeline и checkpoint после Prompt 18                 |
| Видимость | пользователям портала не видна                                                  | флаг `takeoff.ai`, по умолчанию выключен                                                 |

Дополнительно:

- test-разбиение фиксируется до обучения и не меняется по результатам;
- лицензия — технический гейт: зависимость или веса без записи в матрице лицензий не используются.
  Ultralytics заблокирован до решения владельца о коммерческой лицензии, Unsloth Studio в Quantor не
  встраивается;
- Unsloth — зависимость обучения, и производственный инференс не обязан её содержать;
- клиентские чертежи и данные PlanSwift не уходят во внешние API — ни из лаборатории, ни из портала —
  без отдельного решения владельца;
- если ни один pipeline не прошёл гейт, Stage 2B останавливается как честный эксперимент, и плохая
  модель в портал не интегрируется.

## Последствия

- Отчёт эксперимента и функция портала — разные артефакты с разными критериями приёмки.
- Промты 19–24 (производственная интеграция) без PASS Prompt 18 и утверждения владельца не
  выполняются.
- Прогон без хешей не может быть промотирован: воспроизводимость — условие, а не пожелание.
- Обучение требует GPU. Без него оно помечается BLOCKED, а не имитируется.

## Отвергнутые альтернативы

- **ML-зависимости в `apps/api`.** Холодный старт, размер образа и лицензии производственного
  процесса зависели бы от эксперимента.
- **Эксперимент прямо в портале за флагом.** Флаг прячет интерфейс, но непроверенная модель уже
  стоит в производственном пути.
- **Ослабить гейт после результата.** Гейт, подогнанный под модель, ничего не проверяет. Допустим
  только новый эксперимент с новой, заранее объявленной версией гейтов.
