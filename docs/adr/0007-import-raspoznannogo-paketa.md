# ADR-0007. Импорт распознанного пакета: legacy-v1 сейчас, manifest-пакет потом

Статус: принято, 2026-09-04

## Контекст

Собственная распознавалка выдаёт ZIP без манифеста: исходный PDF, `*_blocks.json`,
`*_results.md` и необязательный `*_results.html`. Роли файлов определяются по именам.
Проверено на эталонном архиве: `schema_version=1`, `coordinate_space=normalized_page_top_left`,
77 страниц, 383 блока, 320 блоков со ссылкой `crop_url` на внешний сервис.

## Решение

Поддерживаем текущий формат как `recognized-package/legacy-v1` — тонким импортёром, задача
которого открыть уже распознанный проект, а не распознавать заново.

Обязательные свойства импортёра:

- архив считается недоверенным: запрещены выход за пределы каталога, абсолютные пути,
  символические ссылки; ограничены число файлов, сжатый и распакованный размер, степень сжатия;
- `results.html` хранится как артефакт, но никогда не является источником правды и не
  отображается как доверенный HTML;
- `crop_url` сохраняется только как метаданные. **Сервер их не загружает**: это делает пакет
  несамодостаточным и открывает SSRF. Область при необходимости воспроизводится из PDF по
  нормализованным координатам;
- `results.md` разбирается терпимо: нужен лишь индекс секций `### BLOCK #<n> [<TYPE>]: <id>`
  и сырой текст между заголовками. Семантика (Summary/Description/Entities) не разбирается;
- блоки-штампы без секции в Markdown — полноценные области, а не ошибка;
- импорт идемпотентен по хэшу пакета: повтор не создаёт вторую копию графа объектов;
- при сбое задание завершается с безопасным кодом ошибки и не оставляет наполовину видимый проект.

Целевой формат v2 (`manifest.json` с явными версиями схем, ролями файлов и контрольными
суммами) описан в `_prompts/stage1/reference/EXPORT_ANALYSIS.md` и **на Stage 1 не реализуется**.

## Последствия

- Портал открывает существующие пакеты без изменений в распознавалке.
- Определение ролей по именам файлов остаётся хрупким местом; это плата за совместимость,
  и именно она мотивирует формат v2.
- Требуется набор явных кодов ошибок валидации, чтобы интерфейс объяснял пользователю причину
  отказа по-русски и без трассировок.

## Отвергнутые альтернативы

- **Сразу перейти на формат v2.** Требует правок в распознавалке и блокирует Stage 1.
- **Скачивать `crop_url` при импорте.** Уязвимость и зависимость от внешнего сервиса ради
  картинок, которые всё равно воспроизводятся из PDF.
