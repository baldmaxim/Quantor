## 3. Пригодность к работе

Отдельный прогон в браузере (9 из 9):

- активный инструмент отмечен на панели;
- Escape отменяет черновик, и Enter после него ничего не создаёт;
- Backspace убирает последнюю вершину: из четырёх точек сохраняются три;
- панорама (Space + перетаскивание) и зум колесом не рождают измерений;
- смена строки обмера сбрасывает инструмент чужого типа;
- Delete удаляет выбранное сохранённое измерение;
- смена листа не переносит черновик на другой лист (раздел 4);
- лист без масштаба даёт `unavailable_no_scale` и подпись «без масштаба», а не ноль;
- счёт считается и без масштаба.

## 4. Найденные дефекты

### 4.1. Черновик переживал смену листа — измерение попадало на чужой лист

**Блокирующий.** Инженер начинал ломаную на листе 1, переключался на лист 2 и нажимал
Enter — измерение сохранялось **на лист 2 с координатами листа 1**. Вершины нормализованы
к своему листу, поэтому на другом те же доли означают совсем другое место.

Черновик масштаба при смене листа сбрасывался, а черновик обмера — нет. Добавлен
`ToolController.resetForSheetChange()` и его вызов при смене листа; поведение закреплено
тестом `tool-controller.test.ts`. Перепроверено живьём: дефект не воспроизводится.

### 4.2. В dev-режиме нельзя было включить пилот на пространство

**Существенный.** Переопределение флага писало автора правки внешним ключом на
`user_identities`, а dev-личность по устройству режима в базе не существует
(`app/auth/dev.py`). Итог: `PUT /admin/feature-flags/{key}` отвечал 503
`DATABASE_UNAVAILABLE`, и локально включить `takeoff.manual` было нечем — то есть
рекомендованный путь включения пилота на своей машине не работал.

Добавлена функция `actor_id(context)`: у личности без строки в базе автор не записывается.
Сведения не теряются — кто и что менял, остаётся в журнале действий. Та же правка
применена к переопределениям настроек, где ошибка была ровно той же.

### 4.3. Идентификация документа и ревизии в рабочей области

Рабочая область показывала только проект и номер листа. Обмер не того чертежа виден
только по результату, поэтому в строку навигации добавлены название документа и подпись
ревизии (`Проекты / Проект / control-sheet.pdf ревизия от сегодня, 13:40`). Данные берутся
двумя запросами по уже существующим маршрутам `GET /revisions/{id}` и
`GET /documents/{id}`.

## 5. Выгрузка CSV

`GET /api/v1/sheets/{sheet_id}/takeoff-export.csv` — по листу, а не по проекту: сложить
измерения разных ревизий значило бы посчитать одни и те же двери дважды (ADR-0019).

- Строка на измерение. Итог по строке обмера едет рядом отдельными столбцами, поэтому
  свёртка ничего не скрывает: у измерений одной строки бывают разные калибровки и правила.
- 29 столбцов, вся цепочка прослеживаемости: проект → документ → ревизия → лист → строка
  обмера → измерение → величина с правилом, версией правила, калибровкой, отпечатком
  геометрии страницы и отпечатком входа.
- Считает сервер. Клиент ничего не пересчитывает: ссылка ведёт прямо на отчёт.
- Состояние расчёта в двух видах: по-русски и кодом (`ready`, `unavailable_no_scale`).
  Недоступная величина — пустая ячейка с причиной, а не ноль.
- Кодировка UTF-8 с меткой, разделитель `;`, запятая в дробной части — то, что русский
  Excel открывает без настройки. Замена точки на запятую — подстановка символа, значение
  не округляется.
- Архивная строка сохраняет название: без него непонятно, чего касается величина.
- Тот же пилотный флаг, та же граница пространства, то же право чтения обмера. При
  выключенном пилоте — 403, у чужого листа — 404.

XLSX не делался: новый тяжёлый модуль отчётов промтом запрещён, CSV достаточно.

## 8. Как начать первый реальный обмер — 5 шагов

1. **Включить пилот.** В админке → «Флаги возможностей» → `takeoff.manual` → включить
   **в пространстве** (не в системе).
2. **Загрузить PDF.** Проект → «Загрузить файл» → обычный PDF. Дождаться подписи «Листы
   готовы»; распознанный пакет не нужен.
3. **Открыть и задать масштаб.** «Открыть» → вкладка «Обмеры» → инструмент «Масштаб» →
   два щелчка по известному размеру на чертеже → ввести размер в мм. В статусной строке
   появится «Масштаб чертежа: … мм/pt».
4. **Считать.** «Новая строка» → название и тип (количество, линия, ломаная, площадь) →
   выбрать строку → одноимённый инструмент → щелчки по чертежу; Enter завершает ломаную и
   площадь, Backspace убирает вершину, Escape отменяет, Delete удаляет выбранное.
5. **Забрать результат.** Внизу панели обмеров — «Выгрузить CSV по листу». Величины в файле
   те же, что на экране, и каждая объяснена правилом и калибровкой.
