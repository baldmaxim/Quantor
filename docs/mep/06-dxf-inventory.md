# DXF: опись без присвоения классов

2026-09-18: по команде владельца сконвертированы семь DWG — шесть архитектурных кандидатов
и один инженерный эталон. Все входные/выходные хеши, версия и хеш ODA, параметры запусков
сохранены вне Git. Семь кодов завершения 0; оригиналы не изменены.

Опись выполнена ezdxf 1.4.4: слои с числами сущностей по типам и пространствам,
определения блоков и прямые INSERT, ATTDEF/ATTRIB, текст и MTEXT с координатами,
layouts, VIEWPORT/VPORT, стили/шрифтовые ссылки, xref, единицы и границы модели.
Текст в определениях блоков имеет локальные координаты; преобразования INSERT сохранены отдельно.
Числа INSERT не означают число рекурсивно развёрнутых экземпляров.

Агрегаты: 7 описей, 5784 текстовых записи, 21 layout, 0 XREF-блоков. Во всех источниках
заданы миллиметры. Это объявленные единицы, а не независимая калибровка. Bbox приблизительна;
для неподдержанных сущностей возможны пропуски. Шрифты не скачивались и не подменялись.

Таблица этажей составлена по явным надписям, отметкам и именам реально вставленных блоков.
Имя экспортного вида в блоке отмечено отдельно: оно не доказывает геометрию всего диапазона.
Покрытие требуемого диапазона полностью не подтверждено. Имена исходных файлов доказательством
не считались. Ни один архитектурный файл не выбран.

Точных дублей сущностей Model вместе с определениями блоков не найдено. Одна пара имеет
значительное частичное совпадение, но различающиеся подписи; это кандидаты вариантов,
а не взаимозаменяемые дубли. Совмещение координат не выполнялось.

Для инженерного источника подготовлены 6 строк кандидатов слоёв и 9 непустых групп кандидатов
блоков по сходству имён с классами профиля. Количества пересекаются между группами;
отсутствие совпадения имени не означает отсутствие объекта. Присвоено классов: 0.

Проверки: семь входных и выходных SHA-256 после чтения; синтетическая проверка слоёв,
пространств, атрибутов, единиц и read-only; `pip check`; `pnpm lint:licenses`.
Сырые тексты, пути, имена CAD-объектов, цитаты и полные таблицы — только в датасете.
STOP. Без OCR, растра, моделей, обучения и изменения ядра контрактов.
