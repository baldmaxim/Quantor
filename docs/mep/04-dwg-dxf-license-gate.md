# Локальный DWG → DXF: лицензионный гейт

Решение владельца 2026-09-17: вариант А, без обучения и семантического сопоставления.

`vision[mep-dxf]` закрепляет **ezdxf 1.4.4**, MIT. Лицензия проверена по
[тегу v1.4.4](https://raw.githubusercontent.com/mozman/ezdxf/v1.4.4/LICENSE), метаданные —
[PyPI](https://pypi.org/project/ezdxf/1.4.4/). При распространении ezdxf сохраняются copyright
и текст MIT. Extras draw/dev не подключаются. Базовые транзитивные зависимости пакета:
Установлены в отдельное окружение 2026-09-18: pyparsing 3.3.2 (MIT), typing_extensions 4.16.0
(PSF-2.0), numpy 2.5.3 (BSD-3-Clause AND 0BSD AND MIT AND Zlib AND CC0-1.0), fonttools 4.65.0
(MIT). Точные версии и лицензионные метаданные сохранены вне Git; `pip check` пройден.

ODA File Converter — внешний проприетарный инструмент, не Python-зависимость и не часть Quantor.
В [матрице](../../vision/licenses/decisions.json) записаны условия локального использования и
`redistributed: false`. Новая явная команда владельца от 2026-09-18 разрешила агенту скачать
официальный MSI и установить его с настройками по умолчанию; прежнее ограничение установки
владельцем снято. Установщик сохранён только в Windows TEMP, его подпись Open Design Alliance
проверена. Бинарники не копируются ни в Git, ни в датасет и не распространяются.
Владелец отдельно подтвердил принятие условий установленной версии.

ODA установлен в `C:\Program Files\ODA\ODAFileConverter 27.1.0\ODAFileConverter.exe`.
MSI: 27.1.0; FileVersion/ProductVersion: 27.1.0.0.
SHA-256 exe: `5889d64397a935dd7daa5f644c436706d2145d31e033cd2c1cf6a21c6702b9c2`.
Статус установки проверен перед запуском; прежний BLOCKED_NOT_FOUND снят.

[Официальная страница ODA](https://www.opendesign.com/guestfiles/teighaFileConverter) описывает
CLI с исходным/целевым каталогами, фильтром файлов, форматом и флагами рекурсии/аудита.
Выполнены семь запусков с точным фильтром имени, `ACAD2018 DXF 0 0`: без рекурсии и
автоматического ремонта. Оригиналы неизменны; DXF только `$QUANTOR_DATASET_ROOT/mep/dxf/<sha12>/`.

Владелец разрешил конвертировать все шесть архитектурных кандидатов и один инженерный DWG,
без предварительного выбора архитектуры. **Все семь конвертаций и описей выполнены.**
Опись ограничена слоями и количеством типов сущностей, именами блоков
и числом INSERT, ATTRIB/ATTDEF, стилями текста и ссылками на SHX, xref, единицами и масштабом
модели. Отсутствующие SHX/xref отмечаются, не скачиваются. Отсутствие INSUNITS — неизвестные
единицы; масштаб печати не объявляется масштабом модели. Связь с классами MEP не выводится.

`pnpm lint:licenses` проверяет объявленную Python-зависимость. Он не подтверждает наличие ODA
или выполнение условий его лицензии. Дополнительная проверка этих условий обязательна перед
исполнением. Тесты гейта покрывают отсутствие решения, blocked, allow и conditional для ezdxf.
