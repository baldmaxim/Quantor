# Замер измерительного ядра

```bash
pnpm benchmark:measurement            # всё, включая живую базу, если она поднята
pnpm benchmark:measurement --skip-api # только то, что не требует стенда
```

Результат: `docs/stage2a/benchmark-results.json` (для машины) и
`docs/stage2a/benchmark-report.md` (для чтения). Отчёт **создаётся генератором**: числа в
нём и в JSON обязаны совпадать, а две независимые записи одних и тех же величин однажды
разойдутся.

## Почему замер отдельно от тестов

Тест отвечает «сломано или нет», замер — «сколько это стоит». Вывод `pytest` показывает
время своего прогона, а не время расчёта, и выдавать одно за другое нельзя.

## Что где лежит

| Часть          | Где                     | Почему там                               |
| -------------- | ----------------------- | ---------------------------------------- |
| Датасеты       | `benchmarks/datasets/`  | общие для обеих сред                     |
| Арифметика     | `apps/api/benchmarks/`  | там её проверяют ruff и mypy             |
| Слой отрисовки | `apps/web/benchmarks/`  | там его проверяют eslint и tsc           |
| Сборка отчёта  | `scripts/benchmark.mjs` | рядом с остальными командами репозитория |

## Датасет

`measurement_v1.json` — синтетические случаи. Каждый содержит страницу, доказательство
калибровки, геометрию, ожидаемую величину, единицу, допуск и пояснение, откуда взято
ожидание.

Ожидание — **внешнее знание**: аналитика или размерная надпись на чертеже. Датасет,
заполненный собственным выводом программы, доказывает воспроизводимость и ничего не
говорит о правильности.

Отпечаток датасета печатается в отчёте. Сравнивать замеры, снятые на разных отпечатках,
нельзя: это разные наборы случаев.

### Живые чертежи

`live_measurement.example.json` — только форма. Настоящие чертежи весят десятки и сотни
мегабайт и в репозиторий не коммитятся без решения владельца.

Свой набор укажите путём:

```bash
node ../../scripts/py.mjs -m benchmarks.measurement_bench --dataset путь/к/live.json
```

В живом случае размеры страницы не пишутся руками: их извлекает тот же провайдер
геометрии, что и рабочий конвейер. Коэффициент калибровки тоже считает сервер — вписанный
руками, он превратил бы замер в проверку арифметики датасета.

## Пропуски

Разделы, для которых нет условий, помечаются `skipped` с причиной и командами. Ненулевой
код возврата бывает только за расхождение арифметики с датасетом: падать из-за
неподнятого стенда значило бы приучать не смотреть на код возврата.
